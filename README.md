# parcelhub

包裹站点交接台账的本地命令行工具：单件收件登记、按编号查询、多件包裹站点交接。
仅使用 Go 标准库，无需外部服务，全部数据保存在本地文件。

需要 Go 1.24 或更新版本。

## 运行

```sh
go run . --help          # 显示应用名与帮助（无参数、-h 同样生效）
go build -o parcelhub .  # 或构建可执行文件
```

## 命令

所有命令支持 `--data <文件>` 指定本地数据文件（默认 `parcelhub.json`）。
文件不存在时自动建立空台账；内容损坏时拒绝读写，不会覆盖原文件。

```sh
# 登记：包裹编号在数据文件内唯一，成功后状态为在站
parcelhub register --parcel P001 --site 上海站

# 查询：当前站点、状态，以及按提交顺序排列的完整轨迹
parcelhub query --parcel P001

# 交接：一次提交多件包裹，全部校验通过才一起改归目的站点
parcelhub handover --request R1 --from 上海站 --to 杭州站 --parcels P001,P002
```

交接表示实物已完成移交。请求号用于去重：同一请求号以相同源站、目的站和
包裹集合（顺序无关）重复提交时，返回首次成功的结果且不追加轨迹；同一请求号
换任何业务内容则报冲突。失败的首次提交不占用请求号，纠正后可重试。

未知命令或参数会在标准错误中提示并以状态码 2 退出。
